\begin{abstract}
This report inventories the LVN Heo1 experiments found in the PPC and standalone LVN logs. It records the configuration used by each run and the evaluation metrics printed in the logs: voltage RMSE, magnitude RMSE, angle RMSE, active/reactive residual infinity norms, residual distribution statistics when available, and final test metrics when present. The results cover early K=40 informed and flat sweeps, S-base/share-grid reruns, manual loss and k-hop ablations, student-style loss ablations, adapted Armijo variants with and without the nominal-voltage feature, and the Attn8/K40 follow-up jobs.
\end{abstract}


\section{Scope and Log Sources}
The report was generated from 114 LVN/Heo1 training logs under the Alex cluster result tree and the standalone student LVN run directory. The parser used the last validation epoch as the main metric unless a final test line was printed. Some historical Slurm job-output files interleaved multiple jobs into one output stream; this report uses the corresponding per-run training logs under \texttt{results/logs} where available.

\paragraph{Metric definitions.} RMSE and $|V|$ RMSE are in per-unit voltage coordinates. $\theta$ RMSE is reported in degrees. $\dP_\infty$ and $\dQ_\infty$ are the maximum absolute active/reactive power mismatches printed by the evaluation loop in per-unit coordinates after the configured S-base processing. Mean and p95 residual columns are bus-entry distribution summaries printed only by newer logs.

\section{Main Findings}
\begin{itemize}
\item The adapted Armijo change removes the MSE deadlock: MSE-only runs now learn and produce the strongest voltage-prediction metrics among the recent loss-ablation jobs.
\item The nominal-voltage feature \texttt{vn\_log} helps in several DC-start settings, but the no-vn and vn variants are close enough that architecture and optimizer settings matter as much as the extra feature.
\item The low residuals reported in the earlier Claude status table came from the K=40 share-grid reruns, not from the current Attn8 student-Armijo sweep. Those values are direct log values, not a post-hoc scaling.
\item Attn8 is useful in supervised MSE settings, especially DC-start A40 K10 Attn8, but PINN-only and PINN+MSE variants often trade better residual behavior for worse voltage angle accuracy or become unstable at late epochs.
\item K=40 is much more expensive. In the recent A40/A100 K40 runs, several jobs were partial at parse time and did not consistently outperform K=10 on voltage RMSE.
\end{itemize}

\section{Configuration Notes}
The most important configuration axes in the logs are: start condition (DC-informed versus manual flat), solver depth $K$, hidden width $d_{hi}$, number of attention layers, Armijo handling, learning rate, batch size, train/validation/test split, S-base rebase, and whether \texttt{vn\_log} is supplied as an explicit per-bus feature. Historical K=40 runs often used \texttt{BATCH=8}, \texttt{LR=3e-6} or earlier defaults, and train ratio 0.3333. Recent student-style runs use \texttt{BATCH=32}, \texttt{LR=1e-4}, train ratio 0.8, and the adapted Armijo update that always applies the selected step size.

\section{Interpretation and Recommended Next Steps}
For voltage prediction on the LVN Heo1 grid, the supervised MSE objective remains the cleanest training signal. The adapted Armijo implementation is necessary for MSE-only training because the older reject-step Armijo could detach the voltage prediction from the learned heads. For physics feasibility, the K=40 share-grid experiments show that low residual regimes are possible, but those runs use a different optimization regime from the recent student-style sweeps. The next controlled experiment should therefore rerun the low-residual K=40 share-grid configuration and the best student-style Attn8 MSE configuration under the same split, batch size, learning rate, S-base path, and checkpoint-selection criterion. A residual-aware checkpoint criterion, such as validation mean $|\dP|+|\dQ|$ or NR-polish iterations, should be logged alongside voltage RMSE.
